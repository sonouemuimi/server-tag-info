# Hide Blocked Messages — 无占位测试修复版

适用于普通 Revenge / Revenge Xposed 的 Vendetta 兼容插件接口，版本 `1.0.0-test2`。
针对原 HideBlockedAndIgnoredMessages 留下 `[Filtered message. Check plugin settings.]` 的问题重写过滤逻辑。

## 安装

先关闭原来的 **HideBlockedAndIgnoredMessages**（或其他隐藏屏蔽消息插件），再到 Revenge → 插件 → + 添加：

```text
https://raw.githubusercontent.com/sonouemuimi/server-tag-info/main/hide-blocked-messages/
```

安装启用后，**强行停止 Discord 并重新打开**，清除原插件已经生成的占位行。
不需要修改手机文件、不需要安装 Python。这个目录是独立插件，旧插件可以保留为关闭状态用于回退。
两者存储独立，旧插件的开关不会自动转移。

## 开关

| 开关 | 默认 | 行为 |
|---|---|---|
| 隐藏被屏蔽用户的消息 | 开 | 过滤被屏蔽用户的消息，不生成自定义占位提示 |
| 隐藏被忽略用户的消息 | 开 | Discord 有 `isIgnored` 接口时生效 |
| 同时隐藏其他人回复他们的整条消息 | 开 | 回复目标已确认被屏蔽/忽略时，隐藏整条回复 |
| 保留回复时隐藏被屏蔽者的引用 | 开 | 上一项关闭时，只去掉自动回复引用，保留回复正文、附件等 |

修改开关后重新进入频道；从 test1 更新后需要强行停止并重开 Discord，清除旧 Hook 和此前已处理的缓存。
插件不删除 Discord 服务器上的消息。正文中的手工引用、截图、普通 @ 提及不属于自动回复预览，不会据此删除正常消息。

## test2：成员资料加载兼容性

用户反馈 test1 使用期间，部分名字先显示普通用户名和默认颜色，约十几秒后恢复服务器昵称、身份组颜色和图标。截图符合成员资料延迟补全，但尚不能证明唯一原因。

代码审查发现 test1 在全局 `FluxDispatcher.dispatch` 中阻止或替换消息事件，可能影响除消息列表外的成员资料处理。模拟回归场景中：普通用户回复被屏蔽者时，test1 会连同该回复携带的成员资料一起阻止传递。

test2 的调整：

- **完全移除全局 dispatch Hook**。原始新消息、历史消息、回复和成员资料事件正常传给 Discord 所有 Store。
- 保留原始 `MessageStore.getMessages()` 集合对象及其方法，不再创建集合 Proxy。对已识别集合的 `toArray()` 输出进行显示过滤，不删除真实缓存。
- 缓存相同的过滤结果及去引用后的记录，避免数据未变化时不断返回新数组/对象；昵称、角色资料仍由 Discord 处理。
- 支持两种回复字段拼写，保留“隐藏整条回复”及“只去掉引用”两种选择。
- 不修改 RowManager，不清空原消息内容，不生成英文占位提示，不发送伪造消息事件。
- 会话作者索引最多 10,000 项，不写盘；弱引用缓存随对象释放，关闭插件时撤销 Hook 和索引。

## 已验证与限制

`node test-plugin.cjs` 通过 18 项模拟集成测试，新增成员资料事件完整传递、集合身份保持、稳定数组/记录引用、正常身份组更新等回归检查。test1 会在新的成员资料回归检查中失败。
这些是本地模拟集成测试，**没有在 Discord 344.13 / 用户手机上完成实测**，所以继续标为测试版；需要验证彩色昵称的延迟是否改善，以及消息是否仍然隐藏。

- 如果 Discord 的列表绕过 `getMessages().toArray()`，或集合在每个实例上提供自有 `toArray` 方法而非类方法，当前显示过滤可能不覆盖。会记录一次警告，不恢复使用会干扰全局数据的事件拦截。
- `toArray` 是共享读取接口，不是已验证的专用 UI 接口；其他读取者也可能获得过滤结果。完整网络事件、MessageStore 原始缓存和 `getMessage` 保持不变。
- 引用作者和被引用消息都不在客户端缓存时，不能可靠判断是否被屏蔽；不会把所有未知/已删除引用误判为屏蔽消息。
- 插件启用前已经生成的 UI 行，需要退出频道或重启客户端重新加载。
- 改变用户屏蔽状态后，重新进入频道；列表下次读取时会按当前关系过滤。
- 不承诺隐藏成员列表、表情反应、搜索结果、正在输入状态和系统通知等所有入口。
- 不要与旧隐藏插件同时开启，尤其旧插件会改写共享消息对象和生成占位行。

遇到问题请提供 Discord / Revenge 版本、对应开关、是实时新消息还是重新进入频道后的历史消息，以及截图。无需提供账号 Token 或完整消息数据库。

## 回退

关闭此插件，重新开启原插件，然后强行停止并重新打开 Discord。可正常卸载此插件。
